# 多国家独立出口管理系统

适用于 Ubuntu 22.04/24.04、Debian 12。安装器会部署节点管理后台、3 x- ui、TL S证书、订阅和多国家独立出口。

## 一行安装

请先在云安全组放行 TCP 22、80、443。然后使用 root执行：

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/GaryTung/newinstall/main/install.sh)"
```

安装向导会要求选择初始协议和端口，并可选择使用域名证书或公网 IPv4证书。

默认会关闭 Ubuntu 本机的 UFW/netfilter-persistent，并开放本机全部 TCP/UDP 端口，公网访问范围由 Oracle Cloud 的 VCN/安全列表/NSG 控制。如需保留本机防火墙，可在下载安装包后以 `OPEN_ALL_PORTS=0` 运行安装器。

## 主要功能

- VPS直连节点与多国家独立出口同时存在；
- 每个国家可独立选择 VLESS、Trojan 或 Hysteria2；
- 每个国家使用独立端口、网络命名空间、Open VPN和出口；
- 每条线路持久使用独立内部网段，删除或新增其他线路不会改变现有转发地址；
- 严格锁定国家，不会在目标国家失败时跳到其他国家；
- 支持住宅优先、仅住宅、仅机房或全部IP；
- 支持添加、删除、保存和手动切换单个国家线路；
- 每条国家线路可在原后台直接开启带账号密码的 SOCKS5，供指纹浏览器使用；
- 提供单节点链接及包含全部国家线路的总订阅；
- 提供通用订阅和 Clash/Mihomo订阅；
- 自动申请并续签 TLS证书；
- 节点目录更新与各国家可用性检测相互独立；
- 低内存检测、热备用和失败自动恢复。

## 低负载版本与 DNS 缓存（.44）

- 已移除下载测速、测速临时隧道、自动测速择优和对应页面按钮；旧测速配置及结果不再影响出口选择。
- 保留当前出口健康检查、按国家和 IP 类型的故障恢复，以及手动指定 IP；当前出口正常时不会因速度比较主动切换。
- 可用内存低于 192 MiB（或无法可靠读取）时暂缓开始新的目录拉取和候选检测，不停用已有出口的健康检查；总内存不超过 1.5 GiB 时，每批候选检测和镜像拉取最多使用一个工作线程。这是任务开始前的保护，不是进程内存硬限制。
- 单个节点资料响应上限 8 MiB；超限中止本轮更新并保留既有节点清单，不使用截断内容。
- DNS 缓存只在实际访问域名时工作，不主动扫描域名、不测速、不创建额外 VPN 隧道。它会占用少量内存和处理时间，同时减少重复 DNS 请求，并非零开销。
- 缓存每代理进程默认最多 1,024 条，遵守 DNS/CNAME TTL 且最长 300 秒；失败不缓存，相同域名并发查询合并，切换 VPN 或 tun0 状态/地址变化时失效，各国缓存相互隔离。线路越多，缓存总量也会增加。
- 修正 IP 地址 TLS 节点订阅中无效的 ECH 字段，避免部分客户端报 `EncryptedClientHelloConfigList contains no valid configs`；仍严格验证 TLS 证书，域名和 REALITY 节点设置不变。升级后请在客户端更新订阅；手动导入的受影响节点需重新复制链接导入。
- 修复代理并发连接可能误用另一连接对象的问题；这不代表所有断线原因都已排除。
- 保留入站端口、订阅地址、客户端凭据和 SOCKS5 账号密码。本次降载不保证消除所有内存或网络故障，仍需根据实际资源使用排查。

## stability.31 稳定性规则

- “OpenVPN握手成功”不再等同于“完整出口已验证”；
- 连接成功后记录真实出口、国家、服务商和IP类型；
- 最近20分钟完成完整出口验证的节点优先作为备用；
- 当前出口健康检测使用三个独立公网地址服务容错；
- 单个地址服务临时故障不会立即触发线路切换；
- 自动连接最多尝试8个符合策略的同国家候选节点；
- OpenVPN连接超时缩短到20秒，减少失效节点拖延；
- 自动清理超过90秒的遗留测试进程；
- 批量检测降低节点文件写入频率，减少一核低内存VPS卡死概率。

## 默认国家线路

- `7825`：美国，Hysteria2，住宅优先；
- `7866`：日本，Trojan，全部IP（排除 KDDI/AS2516）；
- `7888`：韩国，VLESS，全部IP（排除 KT/AS4766）。

后台可以修改或删除默认线路，也可以从节点国家清单新增其他国家。

## 防火墙

除 SSH、HTTP和HTTPS外，还需要在云安全组中放行：

- 后台管理端口，默认 TCP `8787`；
- 3x-ui面板端口，安装时指定；
- 总订阅端口，默认 TCP `2096`/`2097`；
- VLESS/Trojan节点使用对应 TCP端口；
- Hysteria2节点使用对应 UDP端口；
- 开启指纹浏览器 SOCKS5 后，还要在云安全组放行后台显示的 SOCKS5 TCP端口。

不要向公网开放内部代理端口 `7928` 或各网络命名空间的内部 SOCKS端口。后台开关创建的是另一组带强制账号密码验证的公网 SOCKS5端口；它本身不加密，必须保管好账号密码，并建议在云安全组中限制来源 IP。

## 指纹浏览器 SOCKS5

进入“多国家独立出口”，在目标国家线路中打开“启用指纹浏览器 SOCKS5”，确认端口后点击“保存并应用本线路”。系统会自动生成账号密码、建立入站并绑定该国家出口。保存后点击“复制 SOCKS5 信息”，把服务器、端口、用户名和密码填入指纹浏览器即可。以后后台自动切换该国家的 VPNGate IP 时，指纹浏览器配置无需修改。

## 管理命令

```bash
sudo ml info
sudo ml status
sudo ml credentials
sudo ml channels
sudo ml logs
sudo ml restart
```

`sudo ml info` 会集中显示节点管理后台、3x-ui 面板、订阅地址、证书状态和各服务状态。安装成功后也会在终端末尾自动再次显示这些信息。

## 升级

现有服务器执行下面命令升级。升级器会备份程序、通道配置、运行记录和3x-ui数据库，迁移旧版重复内部地址，并保留后台账号、节点端口及订阅凭据。升级期间代理和后台服务会短暂中断，随后各通道自动重连。

已有的 systemd 应急暂停配置（`VPNGATE_BACKGROUND_PAUSED=1`）保持不变，升级不会擅自恢复暂停的拉取或检测任务；处于该模式时，后台仍为只读。重跑核心安装器也会原样保留已有 `/etc/default/aimilivpn`，不覆盖其中的暂停、并发数、自定义路径和端口；只有首次安装才创建默认环境配置。旧版测速文件及结果可能保留用于备份/回滚，但新版程序不再加载它们。

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/GaryTung/newinstall/main/upgrade-dashboard.sh)"
```
